# 데이터 결합 레시피 — 시연판

공모전 제안 시연판. **공개 메타데이터로 구성한 예시이며 원-윈도우 공식 서비스가 아님.**

질문 3개(따릉이 수요예측·재배치 / 날씨·교통량 고려 교통사고 위험지역 / 폭염 × 온열질환 다발 지역)에 대해
같은 질문을 ① 현행 검색 ② 질문 분해만 ③ 분해 + 결합 그래프 세 조건으로 나란히 보여 주고,
③에서는 재료 데이터·붙이는 법·주의·축별 신뢰등급(A/B/C)과 근거 문장을 담은 레시피 카드를 보여 준다.

## 데이터
| 파일 | 내용 |
|---|---|
| `data/dataset_ids.json` | 사용한 공공데이터포털 데이터 ID 목록 |
| `data/datasets.json` | 상세 페이지의 공개 메타데이터(데이터명·제공기관·설명문·키워드·공간/시간범위 등)를 옮겨 적은 것. 빈 칸은 빈 칸 그대로 |
| `data/axes_manual.json` | 결합축 직접 판독(등급 + 설명문 원문 인용) |
| `data/axes.json` | 규칙(정규식) 1차 추출 + 직접 판독 결과. 빌드 때 생성 |
| `data/recipes.json` | 질문별 현행 검색 요약(기획서 근거①, 2026.11.20 실측), 후보, 선택 이유, 카드, 그래프 배치 |

- 근거 문장은 `scripts/extract_axes.mjs`가 설명문 원문과 글자 단위로 대조하고, 원문에 없으면 빌드가 실패한다.
- 원-윈도우 AI 검색 API는 호출하지 않는다. 정확도·재현율 같은 수치는 넣지 않는다.
- 분석·추적 스크립트, 외부 글꼴, 로그인 없음.

## 실행
```
npm install
npm run dev        # 로컬 확인
npm run build      # dist/ 생성
python -I scripts/fetch_metadata.py --refresh   # (선택) 메타데이터 다시 받기
```

- 기획서 캡처용 화면: `?capture=1#q1` (카드의 단계 목록·주의 일부를 접어 한 화면에 담음)
- QR: `npm run qr -- https://배포주소/` → `output/qr.png`
